BLOOD BANK MANAGEMENT SYSTEM (Flask + MongoDB)

1. Install MongoDB Community Server and make sure the service is running.
2. Open this folder in VS Code, open a terminal inside it.
3. python -m venv venv
   Windows:   venv\Scripts\activate
   Mac/Linux: source venv/bin/activate
4. pip install -r requirements.txt
5. python app.py
6. Open http://127.0.0.1:5000 in the browser.
